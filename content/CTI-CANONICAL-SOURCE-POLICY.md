# CTI Website — Canonical Source and Asset Policy

Effective 2026-10-20. Approved project direction.

## Authority
- **GitHub `bluetallitot-hub/cti-website` is canonical** for the CTI website, its existing image assets, historical content, captions, and asset metadata.
- Treat information and media already committed to the repository as verified and approved for ongoing website work unless the project owner explicitly requests correction.
- Google Drive and external sources are supplementary sources for new imports, research, or backup; do not re-open verification of existing GitHub material as a routine prerequisite.
- Existing original and restored files are preserved; do not delete, overwrite, or rename them solely to tidy the archive.

## Operational workflow
1. Start with GitHub's existing pages, `content/asset-registry.json`, `content/archives/index.json`, `content/gallery.json`, and the image files themselves.
2. Reuse the existing captions, source descriptions, relationships, and approved designs. Do not require renewed provenance approval for assets already in GitHub.
3. For new imports, record the source and seek approval before publishing. Distinguish newly imported, pending material from established GitHub material.
4. Identify missing assets and complete site features rather than repeatedly re-auditing previously accepted images.
5. Preserve the protected backup branch and existing public paths. Test site links before publishing structural changes.

## Earlier audit reports
Reports dated 2026-10-20 are snapshots of earlier verification exercises, **not** a reason to downgrade existing GitHub content to unverified or unapproved. Their null source-reference fields and heuristic classifications are not grounds for removing or blocking existing content.
