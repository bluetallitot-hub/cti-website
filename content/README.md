# CTI website editable content

The website's public pages retain their existing URLs. Service dates are sourced from `content/services.json` and rendered on `services.html`.

The Decap CMS collections under `/admin/` are prepared for biographies, articles, D'vrei Torah, and verbatim archival transcriptions. **GitHub Pages does not provide Decap's GitHub OAuth sign-in**. A separate OAuth gateway must be configured before the editor can sign in. These other collections are not yet wired into existing public HTML pages; adding an entry does not automatically publish a public article.

Do not rewrite approved historical transcriptions. Preserve originals in Google Drive. Keep filenames and public page URLs stable during later migration.
