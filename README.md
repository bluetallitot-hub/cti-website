# Congregation Tiferet Israel Website — First Static Build

This is a no-framework, static HTML/CSS/JS prototype designed for free static hosting (Cloudflare Pages, GitHub Pages, Netlify, etc.).

## Included pages
- Home
- About + history timeline
- Rabbi Phillip Blue
- Services
- D'var Torah archive
- Newsletter archive
- Resources
- Membership / Giving
- Contact / Visit

## Content status
Approved/available Google Drive content is included for the homepage, history, timeline, and Rabbi page.
Unknown information is intentionally represented as clear website stubs rather than invented.

## Images
No third-party research images are included in this build because the Drive image catalog says the binaries have not yet been copied into Drive and reuse rights still need verification. Photo placeholders are present so approved images can be added without changing the page structure.

## Preview
Open `index.html` in a browser, or serve the folder with any static web server.

## Free hosting
This folder can be deployed directly to a static hosting provider. No database, server runtime, package install, or build step is required.
