Newsletter Upload Portal

Prepare a new newsletter, upload its PDF through GitHub, then publish the updated issue index. GitHub sign-in is required only for the two publishing steps; no credentials are stored here.

1. Select the newsletter PDF

Choose a PDF to prepare its filename.

2. Upload the PDF to GitHub

Rename the PDF on your computer to the filename shown below, then open GitHub's upload page and select that file. Commit the upload to main.

Required filename: Choose an issue date

Open GitHub PDF UploadGitHub's web upload has a 25 MiB per-file limit. Larger PDFs must be compressed first. Existing files with the same name should not be overwritten through this flow.

3. Publish the issue index

Once the PDF has been uploaded, download the updated newsletters.json file. Open the existing index in GitHub, replace its contents with the downloaded JSON, and commit the change. The newest issue will automatically appear first on the public Newsletter page.

Edit Newsletter Index on GitHub

Note: GitHub's editor accepts pasted JSON text, not a replacement-file upload. Open the downloaded JSON in a text editor, copy all of it, and paste it into GitHub's editor. The PDF itself is uploaded separately in step 2.
