Leadership Biography Editor

Select one of the 11 non-rabbinic leaders and edit both the short caption biography on the Leadership Team page and the full biography shown when visitors open the leader’s page. The Rabbi’s biography is excluded. Names, positions, photo filenames, order, page layout, and the Rabbi’s page remain fixed. A replacement photo updates both biography and Leadership Team pages.

Replacement is saved as a PNG using the existing fixed filename. The photo on both pages changes when the GitHub asset is replaced; no image paths or names change.

Publish updates

Photo: Prepare the replacement PNG, then replace the existing file with that exact name in the GitHub assets folder. For an existing file, GitHub’s browser uploader may require deleting the old file first and then uploading the replacement. For a leader who currently has initials, upload the new fixed PNG filename. This requires GitHub write access.

Download the updated biography data, open the existing GitHub file, replace its contents with the downloaded text, and commit. The Leadership Team page will show the changes automatically, without changing the page formatting or photograph filenames.

Open Biography Data in GitHub

To publish, open the downloaded JSON in a text editor, copy all its contents into GitHub's editor, and commit. This pre-authentication editor cannot commit changes itself.
