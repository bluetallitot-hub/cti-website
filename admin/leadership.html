Leadership Biography Editor

Select one of the 11 non-rabbinic leaders and edit both the short caption biography on the Leadership Team page and the full biography shown when visitors open the leader’s page. The Rabbi’s biography is excluded. Names, positions, photographs, order, page layout, and the Rabbi’s page are not editable.

Publish updates

Download the updated biography data, open the existing GitHub file, replace its contents with the downloaded text, and commit. The Leadership Team page will show the changes automatically, without changing photographs or formatting.

Open Biography Data in GitHub

To publish, open the downloaded JSON in a text editor, copy all its contents into GitHub's editor, and commit. This pre-authentication editor cannot commit changes itself.
