Add an Archive Record

Enter the source information, original photograph or scan, caption, and full transcription. The public archive automatically places new records in chronological order and uses the existing archive layout.

Publish

1. Upload the image to GitHub's assets folder using the exact filename above. The original image will not be edited.

Upload Original Image

2. Download the updated archive index and paste it into GitHub's content/archive-additions.json editor, then commit. New entries are sorted by date automatically.

Edit Archive Index on GitHub

GitHub's browser uploader accepts files up to 25 MiB. A selected image stays on your computer until you upload it to GitHub. This editor does not upload files or publish automatically.
