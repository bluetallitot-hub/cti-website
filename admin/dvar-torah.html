D’var Torah Publishing

Add a document and optional podcast link to the existing D’var Torah card layout. This does not edit sermon content or change the public card design.

Or select an exported PDF or Word document to upload to GitHub:

Publish to GitHub

If using a PDF or Word file, first upload it to the GitHub assets folder with the exact filename above. If using a public Google Docs link, skip this step.

Upload Document on GitHub

Then download the updated index, replace the contents of content/dvar-additions.json in GitHub, and commit. Upload a selected PDF or Word file first. The new card will appear in the existing D’var Torah layout.

Edit D’var Torah Index on GitHub

A Word document is offered as a downloadable file; it is not converted into an HTML sermon. Google Docs links must have appropriate sharing permissions. This portal cannot upload or publish without GitHub sign-in.
