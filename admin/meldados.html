Meldados — Memorial Records

Draft editor. Names and dates come only from approved records, never from reading the photographed plaques. Export and commit the JSON file to publish. Portraits can be selected, cropped, resized and downloaded here; GitHub upload is a separate publication step. No payment collection is enabled.

Import replaces the current draft after confirmation. Download a backup first. This editor does not automatically publish changes.

Memorial portrait upload preparation

Choose a photo for the selected memorial. The editor creates a standardized 600 × 600 WebP portrait, with a consistent filename based on the memorial record. Adjust the vertical crop as needed.

Upload prepared portrait to the GitHub memorial pictures folder

For now, the browser cannot publish directly to GitHub. Download the prepared portrait, upload it through the linked GitHub folder, then save and download meldados.json to publish the new photo reference. The biography and other record fields remain unchanged.
