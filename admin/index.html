CTI Website Administration

CTI is hosted on GitHub Pages. Editing and publishing are restricted to people with write access to the GitHub repository. Use the schedule editor below or open a website file in GitHub to make and commit changes.

Service Schedule

Edit dates, times, locations and descriptions, and preview the published schedule. Export changes as a JSON file for GitHub until login is enabled.

Open Schedule Editor

D’var Torah Documents & Podcasts

Add a Google Docs link or upload a PDF/Word document, with an optional podcast link. Existing sermon card formatting stays unchanged.

Open D’var Torah Publishing

Newsletter Upload

Prepare a newsletter PDF, enter its issue information, and update the current issue and archive using GitHub.

Open Newsletter Upload

Leadership Biographies

Select one of the 11 non-rabbinic leaders and edit both the card caption biography and the full biography. The Rabbi’s page, photos, positions and layout remain unchanged.

Open Biography Editor

Archive Transcriptions

Select an existing archival article and edit its archive caption and complete transcription. Original scans and layouts are not editable.

Edit Existing Transcriptions Add New Archive

Meldados Memorial Records

Add and edit memorial names, Hebrew dates, biographies, and portrait references. Export the reviewed records for publication to the memorial board.

Open Meldados Editor

Photo Gallery

Add photographs with captions, or edit existing gallery captions. The Anniversary Album remains read-only.

Open Gallery Editor
