# CTI Heritage Assets

Canonical location for newly approved historical collection assets.

## Structure

Each collection record has a directory named for its record ID, e.g. `CTI-023/`.

- `CTI-023-ORG-1.png` — preserved original source (never altered)
- `CTI-023-ENH-1.png` — enhanced image; disclose AI reconstruction when applicable
- `CTI-023-THM-1.png` — presentation thumbnail

## Migration safety

1. Stage and verify approved files in this folder before changing database paths.
2. Keep existing legacy assets and URLs in place during migration.
3. Update canonical database references only after files exist and are checked.
4. Perform complete functional testing of all images and links before any quarantine or cleanup.
5. Quarantine only confirmed unused legacy files; do not delete original historical sources.

This folder is not a signal to deprecate any existing file automatically.
