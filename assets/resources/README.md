# CTI website resources

This directory holds **public, downloadable resources** used by the CTI website (for example, newsletters, prayer-book material, service slides, and melody-learning resources).

## Organization

- `newsletters/` — published congregational newsletters, organized by year.
- Future public resources may be grouped into `prayer-books/`, `service-slides/`, and `melodies/` when approved files are ready.

Keep original Heritage and Biography photographs in their canonical `assets/heritage/` and `assets/biographies/` directories. Do not use this folder for obsolete pages or temporary email previews; those belong in the unpublished `quarantine/` recovery area.

When moving an existing published asset, update all links and data references in the same commit before removing its old path.
