# New uploads — CTI website inbox

Upload new, unsorted images, PDFs, audio recordings, and other website materials into this folder. Original filenames are fine.

The website maintainer will review each item, confirm any uncertain identifications, assign a descriptive filename, preserve source originals when appropriate, move it to its permanent location under `assets/`, and update website references.

Do not link public website pages directly to files in `assets/new/`. Once an item is processed, remove it from this inbox. GitHub `main` is the canonical website source; Google Drive is a downstream backup.
